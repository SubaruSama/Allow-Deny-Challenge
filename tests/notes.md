# Test Driven Development (TDD)

[TDD - Martin Fowler](https://martinfowler.com/bliki/TestDrivenDevelopment.html)

Antes de implementar as funciodalidades descritas no documento description.md, será necessário escrever os testes que deverão ser aceitos. Os testes estão contidos em uma `test suite`.

A biblioteca utilizada neste projeto será o ``unittest`` devido a sua simplicidade e batteries included, ou seja, não é necessário instalar bibliotecas adicionais.

No TDD é utilizado o fluxo de RED, GREEN, REFACTOR.

* Red — think about what you want to develop
* Green — think about how to make your tests pass
* Refactor — think about how to improve your existing implementation
[CodeAcademy](https://www.codecademy.com/article/tdd-red-green-refactor)
